# Oddmash UI 0.10.0

## Highlights

- Accessible ToggleGroup for single and multiple selection (#96).
- DateCalendar supports exact inclusive local ISO date bounds, keyboard navigation clamping, and disabled out-of-range days (#143).

## Compatibility

Existing date controls, ESM entry points, React 18.3.1 and React 19 support are preserved. No new runtime dependencies.

## Verification

Calendar feature CI passed React 18/19 quality and all six browser combinations. Release promotion and npm publication remain pending.
